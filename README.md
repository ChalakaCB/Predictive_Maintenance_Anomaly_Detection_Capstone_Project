# Predictive Maintenance Anomaly Detection Capstone Project

## Project structure

```text
.
├── data/                              # Local only; not included in Git
│   ├── raw/
│   │   └── MetroPT3(AirCompressor).csv
│   └── processed/                     # Generated by preprocess.py
│       ├── train.csv, val.csv, test.csv
│       ├── horizon_label_<N>min/       # Full-pool rebalancing, random split
│       │   └── train.csv, val.csv, test.csv
│       └── chrono_horizon_label_<N>min/ # Chronological, train-only rebalancing
│           └── train.csv, val.csv, test.csv
├── docs/
│   ├── MetroPT3_ETL.ipynb              # Original ETL reference
│   ├── metadata.md                    # Feature descriptions
│   └── results/
│       ├── model_comparison.csv
│       └── tuning_trials.csv
├── src/
│   ├── preprocess.py
│   ├── traditional_ml.py
│   └── models/                        # Generated locally; .joblib ignored by Git
│       └── horizon_label_<N>min__<model>.joblib
├── .gitignore
├── requirements.txt
└── README.md
```

For per-target folders and models, N is 20, 30, 40 or 50. A fresh clone may not
contain `data/` or `src/models/`: ignored files and empty directories are not
distributed by Git. Create `data/raw/` manually and place the original CSV there;
the scripts create the output directories automatically. Frontend/backend and
Docker configuration will be added by the application team; they are not part
of this branch yet.

## Getting started after pulling

Use a project Python environment, then install dependencies with the same Python
interpreter that will run the scripts:

```bash
python -m pip install -r requirements.txt
```

Place `MetroPT3(AirCompressor).csv` in `data/raw/`, preserving the exact filename.
No personal drive path needs to be configured. Generate the data and models:

```bash
python src/preprocess.py
python src/traditional_ml.py
```

Preprocessing generates all three dataset variants shown above. Traditional ML
reads only `data/processed/horizon_label_<N>min/`, fits 88 parameter trials and
saves 20 models. A successful run ends with `Finished: 20 models, 88 parameter
trials.` It also writes the two result CSVs under `docs/results/`.
If the correct processed files already exist, only the training command is needed.
Rerunning the scripts overwrites their corresponding generated files; the README
results table is a recorded snapshot and is not automatically refreshed.
